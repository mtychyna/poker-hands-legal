# Poker Hands Android application
## Privacy Policy (EN)
Last updated: September 15, 2026
### General Provisions
Policy - current Privacy Policy

Application - Poker Hands application, made for Android operating system.

Developer - the private person, created and distributed Application.
### User data
Application do NOT collect any personal User data. Application do NOT track User between sessions and do NOT share anything with third parties.
### What is stored locally
All data stays on the User device and is removed together with the Application:

- Training streak, training statistics and accuracy.
- Theme, suit style and language preference.
- Crash reports preference.
### Crash reports
Anonymous crash reports may be sent to help Developer fix bugs. Such reports contain no personal identifiers. User can opt out at any time in Settings - Privacy - Send anonymous crash reports.
### Permissions
The only Application permission for Internet usage. It is required to show Policy inside the Application and to send anonymous crash reports if User did not opt out.
### Data transfer
No data transmission at all, except anonymous crash reports described above.
### Changes to this Policy
Policy can be updated. Actual version is always available by the public link inside the Application, in Settings - Privacy.
